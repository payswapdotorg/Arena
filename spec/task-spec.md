# Task Specification TS1.0

TaskSpec is the reproducible unit of capability-development work.

## Structure

A TaskSpec contains:

- task identity/version;
- capability labels;
- difficulty;
- domain;
- initial state reference;
- instructions;
- objectives;
- constraints;
- permitted tools;
- prohibited shortcuts;
- expected outputs;
- completion criteria;
- evidence criteria;
- environment requirements;
- evaluator bindings;
- verifier bindings;
- expert qualification requirements;
- data-rights metadata.

## Task classes

- demonstration;
- correction;
- critique;
- preference;
- diagnosis;
- long-horizon execution;
- tool-use;
- environment exploration;
- adversarial;
- benchmark;
- recovery/failure.

## Quality

High-value tasks require realistic context, discriminative difficulty, observable success/failure, reproducible evaluation, low leakage, clear provenance and declared limitations.

## Long-horizon work

Intermediate state and recoveries are first-class evidence. Final output alone is insufficient where process behavior is part of the target capability.
