# Arena Requirements R1.0

## Capability platform

R1 Create versioned Agent Bodies independently of models.
R2 Bind one Body Version to multiple compatible Cognitive Substrates.
R3 Represent Possession as an independently addressable composition.
R4 Maintain a Capability Graph linking skills, tasks, experts, environments and evaluators.
R5 Turn observed failures into Capability Cases.
R6 Compile Capability Cases into reproducible TaskSpecs.
R7 Qualify experts against evidence-backed competencies.
R8 Match expert requirements to qualified experts.
R9 Run reproducible isolated environments.
R10 Capture expert and agent trajectories.
R11 Capture explicit expert corrections and outcomes without requiring hidden reasoning traces.
R12 Support outcome, process and expert evaluation.
R13 Support deterministic and evidence-backed verification.
R14 Preserve artifact provenance and lineage.
R15 Run learning experiments with baseline/intervention/comparison.
R16 Measure whether interventions change target capability.
R17 Extract reusable Skills from validated trajectories.
R18 Forge immutable Agent Body Versions.
R19 Register Cognitive Substrates through provider-neutral adapters.
R20 Test Body/Substrate compatibility.
R21 Issue composition-scoped Certification records.
R22 Reproduce certification from pinned artifacts/environments.
R23 Publish versioned bodies, datasets, evaluations and environments.
R24 Support private tenant artifacts and releases.
R25 Expose APIs/SDKs for programmatic capability development.
R26 Support asynchronous long-running jobs.
R27 Support idempotent commands and correlation IDs.
R28 Provide audit logs for consequential mutations.
R29 Provide tenant isolation.
R30 Sandbox untrusted executable workloads.
R31 Support expert/task/body/evaluation commercial products.
R32 Measure expert and capability quality.
R33 Provide observability for jobs, environments and certification runs.
R34 Support commercial usage accounting.
R35 Integrate with Epoch through provider-neutral contracts.
R36 Never make Arena dependent on Epoch.
R37 Support domain packs without duplicating core lifecycle authority.
R38 Provide a software-engineering reference body.
R39 Support structural-engineering capability as a future demonstration with explicit professional limitations.
R40 Maintain fresh-session implementation handoff.
R41 Graceful degradation when expert supply is unavailable.
R42 Preserve uncertainty/confidence/provenance.
R43 Distinguish model benchmarks from Agent Body certifications.
R44 Record model/body/environment/runtime versions in meaningful performance results.
R45 Allow Body stability across substrate upgrades subject to recertification.
R46 Prevent professional qualification inference from substrate certification alone.
R47 Export/import body and evaluation artifacts without raw customer data leakage.
R48 Version domain and commercial metadata.

## Non-goals v1

- training or serving a frontier foundation model;
- legal/professional licensure;
- universal physics/CAD;
- unrestricted public arbitrary code execution;
- consumer social network;
- treating benchmark performance as a license to practice a profession.
