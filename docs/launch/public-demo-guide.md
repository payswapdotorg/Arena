# Arena Public Preview - Public Demo Guide

## Overview

This guide explains how any visitor can use the hosted Arena preview to experience the platform's capabilities without requiring any setup or credentials.

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Internet connection
- No Arena account or credentials required

## Accessing the Preview

1. Navigate to the hosted preview URL: `__ARENA_PREVIEW_URL__`
2. You'll land on the Arena home page with a role-aware interface
3. Click "Enter Demo Workspace" to begin the experience

## Tips for Visitors

### What to Expect
- **Deterministic experience**: The demo follows a predefined script
- **No external dependencies**: Everything runs locally in the browser
- **Safe environment**: No actual code changes to real systems
- **Educational focus**: Learn about Arena's capabilities and workflow

### What Not to Expect
- **Live production work**: This is a demo, not a real development environment
- **Custom scenarios**: The demo follows a fixed reference use case
- **Real-time training**: You're observing a pre-computed workflow
- **External integrations**: All tool calls are simulated

### Navigation Tips
- Use the role switcher to see different perspectives
- Click on timeline events to see details
- Explore the Body composition to understand capabilities
- Watch for visual distinctions between different types of information

## Frequently Asked Questions

### Q: Is this a real AI system?
**A:** This is a deterministic demo showing Arena's workflow. It uses pre-computed trajectories to demonstrate the platform's capabilities safely.

### Q: Can I use this for real development work?
**A:** The preview is for demonstration purposes only. For real development, you would need a full Arena deployment with proper credentials and setup.

### Q: How often does the demo update?
**A:** The demo follows a fixed reference scenario. Updates to the demo would require changes to the underlying Arena system.

### Q: Can I save my work or create my own scenarios?
**A:** The demo workspace is reset each time. Custom scenario creation would require a full Arena installation.

### Q: What happens if I make changes?
**A:** The demo is read-only. Any changes you make will be reset when you navigate between scenes.
