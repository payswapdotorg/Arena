# ADR-P001-05 — C005 remains the longitudinal expert-performance read surface; C021's declared C005 dependency recorded as an accepted over-declaration

- **Status:** Proposed (binds downstream dispatch only after TL harvest/merge)
- **Work order:** P001 (issue #153) · **Register row:** R-081
- **Binds:** P002 (composition — no new seam), P006 (acceptance scope)

## Context

The C021 work-order dependency list declared C001/C005/C010/C011/C015, but the delivered
escalation-observability surface consumes C001 (escalation events + requests), C011 (SLA
clocks), C010 (payment states) and C015 (routing decisions) — **not C005**. PR #150 asked:
"is a longitudinal expert-performance projection expected inside escalation-ops, or does
it remain C005's own read surface? Work-order dependency list vs delivered surface
mismatch is disclosed." Silent normalization of this mismatch is prohibited (P001 law).

## Decision

1. **C005 (`packages/expert-performance`) remains the sole owner of the longitudinal
   expert-performance read surface** (its dimensional record families, aggregates and
   frozen `DemonstratedPerformance` read). Escalation-observability adds **no** C005
   projection.
2. The declared-but-unconsumed C005 dependency is **recorded as an accepted
   over-declaration**: the dependency was declared for dispatch safety (C005 needed to be
   merged for the wave to be well-formed) but the delivered surface needed none of it.
   No history rewrite; the mismatch stays visible in the harvest record and here.
3. If operator tooling later needs performance views, it consumes C005's **public read
   port** through the P002 composition root — no new seam, no projection duplication
   (lock rule 16).

## Alternatives considered

1. **Add a C005 projection inside escalation-observability** — rejected: duplicates the
   performance read model, creates a second authority for the same truth, and expands
   P002 wiring for no current consumer.
2. **Rewrite the C021 dependency declaration** — rejected: the roadmap record is
   append-only history; the honest treatment is an explicit disposition, not a rewrite.

## Consequences

- P002 wires exactly four dep sources for escalation-observability (C001/C011/C010/C015).
- The precedent is set for future dependency mismatches: disclose, decide, record —
  never silently normalize.
- No engineering work item is created by this ADR (it is a semantic-closure decision).
