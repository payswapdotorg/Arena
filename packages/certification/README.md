# @arena/certification

The Arena **certification protocol** (Work Order A023; requirements R21, R22, R43, R45, R46; architecture-lock rules 4, 12, 16, 17, 18, 23; docs/architecture.md §10, §13, §14).

## Design law

Arena certifies statements of the form:

> Agent Body B, version V, possessed by Cognitive Substrate M, under Environment E and Runtime Profile R, satisfied Certification Suite S at revision X.

Arena does **not** certify that M alone is a professional. The law is enforced by construction: the subject requires all five scope components, the statement is derived (never caller-supplied), unscoped rendering is rejected, and every statement carries the mandated professional-limitations notice (lock rule 23). The hygiene suite scans sources, contracts, README and canonical object forms for unscoped professional-attestation vocabulary.

## Core objects

| Object | What it is |
| --- | --- |
| `CertificationSuite` | Content-addressed, versioned suite declaration: the ordered stage composition pinning exact A012 evaluator+criteria digests, A013 verifier digests, A022 compatibility requirements, A014 dataset refs and environment/runtime composition requirements; the grant level (`DEVELOPMENT \| CANDIDATE \| CERTIFIED`; declared constraints ⇒ `CONDITIONAL`), the limitations notice, the `supersedes` lineage and provenance. The suite digest **is** the "revision X" of the statement. |
| `CertificationSubject` | The composition under test — B/V × M × E × R (A003 `BodyVersionRef`, substrate ref, `EnvironmentProfileView`, `RuntimeProfileView`), every component REQUIRED; tenant/workspace scoping. |
| `CertificationStatement` | The derived design-law sentence: all five scope components + suite revision + verdict qualifier + granted level + constraints + limitations notice. |
| `CertificationRecord` | The append-once record (kind `certification-run` or `revocation`): DERIVED verdict (`satisfied \| not-satisfied \| unknown` — never a score), DERIVED structured unknown cause (closed reason taxonomy, required iff unknown), DERIVED granted level (a failed or indeterminate run grants NOTHING), DERIVED scoped statement, COMPUTED input digest (R22 reproducibility anchor), per-stage results with closed machine reasons, correlation id + idempotency key, `supersedes` lineage. |
| `evaluateCertificationRun` | The deterministic engine: Body × Substrate × Environment × RuntimeProfile × Suite over the consumed sibling-protocol evidence, fail-closed at every stage. |

## Verdict discipline

Closed conditions, machine-readable reasons, structured unknown causes — never a bare score:

- **verification stage** (A013): satisfied ⇔ the pinned `VerificationRecord` outcome is `pass`; `fail` ⇒ not-satisfied; `unknown` ⇒ method-limitation.
- **evaluation stage** (A012): satisfied ⇔ the pinned `EvaluationRecord` (evaluatorRef + criteriaRef) aggregate is `meets-criteria`; `below-criteria` ⇒ not-satisfied.
- **compatibility stage** (A022): satisfied ⇔ the subject's exact body×substrate pair is `compatible`; `incompatible-with-reasons` ⇒ not-satisfied; `unknown-with-structured-causes` ⇒ method-limitation; cross-tenant evidence ⇒ tenant-mismatch (never a pass).
- **dataset stage** (A014): satisfied ⇔ the pinned dataset manifest resolves by digest with matching identity.
- **composition stage**: satisfied ⇔ the subject's E/R components match the pins; mismatch ⇒ composition-mismatch.

Rollup: any not-satisfied stage ⇒ not-satisfied; else any unknown stage ⇒ **unknown** (fail-closed — missing or mismatched evidence can never certify); else satisfied.

## Levels

`DEVELOPMENT | CANDIDATE | CERTIFIED | CONDITIONAL | REVOKED` (spec/quality-model.md) — lifecycle states of a scoped claim, never universal professional ratings. A satisfied run grants the suite's `levelGrant` (or `CONDITIONAL` when the suite declares constraints); failed/unknown runs grant nothing; `REVOKED` is the effective state of a prior claim after an append-only revocation record names it.

## Dependencies

`@arena/protocol-core` (canonical JSON + sha256, envelopes, correlation ids / idempotency keys, SchemaRef) and the consumed sibling domain packages `@arena/agent-body`, `@arena/verification` (A013), `@arena/evaluation` (A012), `@arena/compatibility` (A022), `@arena/datasets` (A014) — same-layer domain composition, public guards only, nothing reimplemented.

The reference fabric (suite registry, runner + evidence ledger with supersession and revocation projections, envelope-wired service) lives in `services/certification` (`@arena/certification-fabric`).

## Generated contracts

`contracts/certification/*.v1.json` (9 schemas) are generated by `scripts/generate-contracts.mjs` (the A001 convention; governance G9 auto-discovers the generator). Parity with this TS surface is asserted by `src/contracts.parity.test.ts`; drift by `src/drift.test.ts`.
