# @arena/environment-runtime

The **runtime protocol layer** for Arena environment runs (Work Order **A010**; spec `spec/environment.md` ENV1.0 lifecycle; `docs/architecture.md` §7 (Environment), §16 (multi-tenancy); architecture-lock rules 8, 21; requirements R9, R29, R30, R33).

Pure TypeScript domain package. The ONLY runtime dependency is `@arena/protocol-core` (envelopes, canonical JSON + sha256, branded identifiers, ProtocolError) — reused, never reimplemented. The sibling domain types it composes enter strictly as **type-only imports** (`@arena/environment-protocol`: ResourceLimits / NetworkPolicy / FilesystemPolicy / SecretPolicy, EnvironmentVersionRef, RunAddress; `@arena/job-protocol`: JobId) — the boundary checker permits domain→domain composition on this base, and the guards for those shapes live here, typed against the imported types. Runtime-neutral by construction: no runner/provider string ever enters a canonical or digested object.

## Core objects (all deep-frozen, append-only, no mutation API)

| Object | Purpose |
|---|---|
| `RunRecord` | Content-addressed run declaration: tenant-scoped run id, content-addressed environment ref (A009), A015 job reference, initial snapshot digest, seed, submitted-at, tenant id + the isolation envelope (A009 policy types). Same inputs ⇒ same digest; any change ⇒ new digest. |
| Lifecycle FSM | `requested → provisioning → ready → running → (checkpointing → running)* → completed \| failed \| timed-out → cleaned`. Pure `transitionRunState` rejects every illegal pair with `ILLEGAL_TRANSITION` carrying the offending from/to states; `enforceTimeLimit` produces `timed-out`. |
| `RuntimeEvent` + `EnvironmentEventLog` | The append-only, enveloped, idempotency-keyed event stream of every run (lifecycle transitions, admission decisions, workload steps, checkpoints, results, cleanup) — queryable by run, by tenant and by state. |
| Admission | `evaluateAdmission` / `assertAdmissible`: a run is admitted only if its isolation envelope FITS the environment's A009 bounds (resource quotas, default-deny egress, explicit mounts, declared injection points). |
| `RunCheckpoint` / `restoreToCheckpoint` | Content-addressed checkpoints with per-run restore validation — foreign-run checkpoints, unknown sequences and digest mismatches are rejected. |
| `RunResult` | The evidence-addressable outcome of a completed run, binding A009's `RunAddress` (task version, environment version, run id, initial snapshot digest, trajectory digest, evidence digests — ALL required). |
| `SeededLcg` / `stepLcg` | The determinism primitive: seeded LCG (Numerical Recipes 32-bit) with independent per-(seed, purpose, index) streams — never `Math.random`. |

## Envelope wiring (lock rules 17, 18, 22)

Every wire shape travels inside `@arena/protocol-core`'s `Envelope<T>`: commands (`submit/start/advance/checkpoint/restore/complete/fail/cleanup run`) carry a REQUIRED non-null idempotency key; events (every lifecycle transition) carry the run's correlation id AND idempotency key. Payload schemas are versioned SchemaRefs in the `environment-runtime` namespace.

## Generated contracts

`contracts/*.v1.json` are generated by `scripts/generate-contracts.mjs` (23 schemas) and **ship package-local** — the repository-root `contracts/environment-runtime/` directory is outside this work order's owned surfaces, so root intake is a Tech Lead wiring step. Drift is checked by `src/drift.test.ts` and governance G9 (which auto-discovers package-level generators); parity with the TS surface by `src/contracts.parity.test.ts`.

```bash
pnpm typecheck && pnpm lint && pnpm test && pnpm build
pnpm contracts:generate   # regenerate after editing protocol constants
pnpm contracts:check      # drift check (also runs in pnpm test + G9)
```

See `services/environment-runner` for the in-process reference runner built on this package.
